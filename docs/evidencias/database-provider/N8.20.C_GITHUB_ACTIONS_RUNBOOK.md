# N8.20.C — ejecución GitHub Actions read-only

## Objetivo

Desbloquear `N8.20.C` sin exponer credenciales ni tocar Producción. El workflow consulta únicamente metadata de la BD DEV dentro de una transacción `READ ONLY`, valida el provider EF/migraciones contra el repo y persiste sólo evidencia sanitizada.

## Único secreto requerido

Crear un Repository Secret de GitHub Actions con este nombre exacto:

`SOLQARYN_DESARROLLO_DB_HOST` / `SOLQARYN_DESARROLLO_DB_PORT` / `SOLQARYN_DESARROLLO_DB_NAME` / `SOLQARYN_DESARROLLO_DB_USER` + secret `SOLQARYN_DESARROLLO_DB_PASSWORD`

Valor: la connection string de la base de datos de **Desarrollo** usada por `solqaryn-api-desarrollo`. No usar Producción.

## Ejecución

1. GitHub → `solqaryn/Solqaryn` → `Settings` → `Environments` → `Desarrollo` → `Environment secrets` → `Add secret`.
2. Use las variables canónicas del environment `Desarrollo` y el secret `SOLQARYN_DESARROLLO_DB_PASSWORD`; el workflow construye la cadena en memoria.
3. Value: connection string DEV. Guardar.
4. GitHub → `Actions` → `N8.20.C - DB Provider Read-only Proof`.
5. `Run workflow` → branch `Desarrollo` → `persist_evidence=true` → `Run workflow`.

## PASS esperado

El job debe terminar verde y mostrar `PASS_PROVIDER_IDENTIFIED`. La evidencia sanitizada se publica en:

`docs/evidencias/database-provider/n8-20-c/github-actions/<RUN_ID>-<ATTEMPT>/`

El artifact del workflow conserva la misma evidencia durante 14 días.

## Datos que NO se persisten

- connection string;
- usuario;
- password;
- nombre de base de datos;
- hostname completo;
- secretos de Render/GitHub.

## Continuidad VAEP

El workflow NO declara por sí solo `LISTO_REAL`. Tras PASS, el controller debe releer HEAD + Sheet, ejecutar REVIEW_FIRST, crear receipt causal, marcar `N8.20.C` `LISTO_REAL` con readback, liberar lease y promover inmediatamente `N8.20.D`.
