# N5.1 — Centro de Reportes: Runbook / Documentación de Release

## 1. Alcance implementado

El parent N5.1 implementa el Centro de Reportes como entrada unificada de navegación en el frontend, reutilizando capacidades especializadas ya existentes. No introduce un nuevo dominio persistente, una fachada backend agregadora ni un nuevo módulo RBAC.

La integración comprende:
- navegación unificada en `/centro-reportes`;
- acceso a reportes administrativos en `/centro-reportes/administrativos`;
- reutilización de contratos existentes para reportes administrativos y estados financieros.

## 2. Permisos y seguridad

- `/centro-reportes` requiere autenticación mediante `authGuard`.
- `/centro-reportes/administrativos` exige `ReportesAdministrativos:Ver` en frontend; el backend conserva su autorización vigente, incluido `ReportesAdministrativos:Exportar` para exportación y la restricción administrativa ya documentada.
- Los estados financieros conservan `Finanzas:Ver`.
- Las exportaciones administrativas mantienen la auditoría explícita existente mediante `IAuditoriaService`.

Este runbook no relaja RBAC ni introduce permisos nuevos.

## 3. Rutas y contratos reutilizados

Reportes administrativos (`/reportes-administrativos`):
- `GET /resumen`;
- `GET /usuarios-accesos`;
- `GET /roles-permisos`;
- `GET /auditoria-resumen`;
- `GET /exportar/{tipo}`.

Estados financieros (`/estados-financieros`):
- `GET /{tipo:int}`.

El Centro de Reportes compone capacidades existentes; no crea un controlador agregador nuevo.

## 4. Rollback

N5.1 no requiere migración de base de datos para este Centro de Reportes. El rollback autorizado se limita a reversión de código en `Desarrollo`, principalmente rutas y componentes del Centro de Reportes. No requiere ni autoriza cambios en Producción, `main`, secretos, dominios o infraestructura productiva.
