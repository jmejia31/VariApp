# VariApp scope lock reference

`PROJECT_ID=VARIAPP`

`REPOSITORY=solqaryn/VariApp`

`PROJECT_SCOPE_LOCK=STRICT`

`EXTERNAL_PROJECT_CONTEXT=DENY_BY_DEFAULT`

Ninguna skill, documentacion, chat, repositorio, memoria o regla de otro proyecto puede utilizarse como contexto de VariApp sin autorizacion explicita del propietario o una entrada activa en `docs/PROJECT_EXTERNAL_CONTEXT_ALLOWLIST.md`.

Las capacidades genericas de plataforma no son autoridad de proyecto y no habilitan contexto cruzado.
