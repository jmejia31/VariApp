# SOLQARYN Skill Routing

| Skill | Activar cuando | No usar para |
| --- | --- | --- |
| solqaryn-project-governance | Toda tarea SOLQARYN | Nunca omitir |
| solqaryn-skill-standard | Estructura/naming/validacion de skills | Producto funcional |
| solqaryn-skill-authoring | Crear/editar/retirar skills | Cambios funcionales ordinarios |
| solqaryn-ui-product | Dashboard, forms, tablas, settings, app shell | Marketing publico puro |
| solqaryn-motion | Animaciones y microinteracciones | UI sin movimiento |
| solqaryn-marketing-design | Home, landing, tienda publica, CMS visual | Dashboard/tablas admin |
| solqaryn-human-writing | UX copy, docs, PRs, informes, mensajes | Evidencia que deba conservarse literal |
| solqaryn-runbook-memory | Lecciones recurrentes confirmadas | Estado vivo o autoridad canonica |
| solqaryn-context-efficiency | Sesiones largas, handoff, contexto duplicado | Eliminar controles para ahorrar tokens |
| solqaryn-low-risk-summary | Resumen interno efimero de bajo riesgo | Seguridad, ADR, migracion, rollback, QA, evidencia, contrato |

Cuando apliquen varias skills, aplicar primero governance, luego skills de superficie, luego skills de calidad/contexto.
